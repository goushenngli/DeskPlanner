# 参数保存问题
设置页面应该有一个功能来恢复默认参数。用户在使用过程中可能会修改参数，导致程序行为异常或不符合预期。提供一个重置按钮可以让用户快速恢复到初始状态，避免因参数设置错误而造成的困扰。  
其中要求参数的存储以配置文件的方式保存,避免使用注册表或数据库的方式  
### 思路有两种:
1. 使用"重置"按钮  
2. 使用配置方案,新的配置方案默认值即为初始状态
